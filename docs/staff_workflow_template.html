Before You Post a PDF

Accessibility check workflow for public documents · Staff guide · Questions: Accessibility Coordinator

The short version

Do not post a PDF directly. Put it in the shared folder “1 - To Remediate” first. Within 2 business days the accessible version comes back, with the same file name, in “2 - Ready to Post”. Post that one.

This applies to every PDF that will be on the website, on the public calendar, or in a shared folder visible to the public or to bidders.

Why we do this

Some people who use our documents cannot see them. They use a screen reader: software that reads the computer screen out loud. A screen reader can only read a PDF that was set up for it. Most of our PDFs are not. When a screen reader opens them, it reads nothing at all, or it reads nonsense. For example, one real bid form read “5HYLVHG” where the page says “Revised.”

A federal rule now requires public entities to make the documents they post online accessible to people with disabilities. That includes bid documents, specifications, addenda, drawings, forms and standards. A bidder who uses a screen reader has the same right to read an addendum as everyone else.

The fix is done for you. The process below adds the hidden information a screen reader needs. The document looks exactly the same; nothing you can see changes.

The shared folders

You will use one shared folder with two subfolders inside it. Make a folder for each project inside both, named with the project number and name.

PDF Accessibility ├── 1 - To Remediate │ └── 260100 Main Hall Renovation │ └── 030-26_Addendum No. 7.pdf ← you put files here └── 2 - Ready to Post └── 260100 Main Hall Renovation └── 030-26_Addendum No. 7.pdf ← you post files from here

Step by step

  1. 1Step 1: Save the PDF in “1 - To Remediate”. Open the shared drive. Go to PDF Accessibility, then 1 - To Remediate. Open the project's folder (or create one, named like 260100 Main Hall Renovation). Upload the PDF. Keep the file's name the way you would post it.
  2. 2Step 2: That's it. The accessibility coordinator is notified automatically. Folder upload notifications alert the coordinator when a file arrives. You do not need to send an email.
    If it's urgent (for example an addendum that must go out today), also send a short email or chat message: “URGENT – Addendum 7 for Main Hall Renovation is in the folder, needs to go out today.”
  3. 3Step 3: Wait for it to come back (2 business days or less). The accessible version appears in 2 - Ready to Post, in the same project folder, with the same file name. The coordinator will let you know when it is there.
  4. 4Step 4: Post the file from “2 - Ready to Post”. Upload or attach that file, not your original. If an older version is already posted, replace it. If a file named like Existing Plans – Set 1 - accessible description.pdf is posted next to it, take that one down: it is no longer needed, because the descriptions are now built into the file itself.

Things that break an accessible PDF
Don'tDo this instead
Don't post a PDF before it comes back from “2 - Ready to Post”. If a deadline makes that impossible, contact the accessibility coordinator right away and we will work it out.
Don't change a fixed PDF: no adding, removing or moving pages, no combining files, no signing or stamping it afterwards. Make all changes first, then send the final file. If something changes later, send the new version through again.
Don't “Print to PDF” or “Save as” a fixed PDF, or run it through a PDF shrinker. Post the file exactly as it comes back.
Don't rename the file after it comes back. Name it the way you want it posted before you send it.

Common questions

Will the document look different?
No. The changes are hidden information that screen readers use. Pages look the same.
Can't I just use Adobe Acrobat's “Make Accessible” button?
It helps, but it misses a lot, especially on scans, forms and drawings. Our process fixes those and then checks every file with the official accessibility checker, so we know it passes.
What about scanned documents, like a signed bid tab?
Send them. They are fixed so a screen reader can read the words.
What about Word or Excel files?
Word (.docx) files are supported alongside PDFs. If you need to post an Excel file or other format, check with the coordinator first.
Is there a size limit?
No. Very large drawing sets come back as one file, the same as everything else; they may take a little longer.
I also see a “reports” folder. Do I need it?
No. The reports are a record of what was fixed. You don't need to post or read them.
What if I already posted something without sending it?
Put it in “1 - To Remediate” now, then replace the posted copy when the accessible version comes back.
Who checks the work?
Every file is tested by an independent accessibility checker before it comes back, and the coordinator reviews the results.
